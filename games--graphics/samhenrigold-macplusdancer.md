## 📝 Summary

### English

MacPlusDancer is a macOS port of the classic Microsoft Plus 2003 dancers, enabling users to add animated visual effects to presentations. To adopt it, clone the repo, install dependencies, run the script, and then embed the dancers into PowerPoint or Keynote. The project is suitable for prototyping, though production use should be preceded by checks on maintenance, licensing, and dependency updates.
