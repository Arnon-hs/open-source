### English

**Project Summary:**
The Microsoft SharePoint-Embedded-Samples project is an open-source collection of developer tools and samples for building on SharePoint Embedded, a document storage API on Microsoft 365. This project enables developers to connect AI assistants to real tools and data through a standard protocol, making it a valuable resource for integrating AI agents with various applications. The project is written in TypeScript and includes various assets, such as React and ASP.NET Core boilerplates, to facilitate development.

**Value Proposition:**
The primary value proposition of this project is its ability to standardize integrations between AI agents and various tools and data sources, making it easier for developers to build and deploy AI-powered applications. This is achieved through the Model Context Protocol (MCP) server, which provides a standardized protocol for connecting AI assistants to real tools and data.

**Practical Adoption Path:**
To adopt this project, developers can start by evaluating the samples and tools provided, such as the MCP server and React boilerplates. They can then use the Postman and Bruno collections to test and integrate the MCP server with their AI agents and tools. Before production, it is essential to perform dependency and maintenance checks to ensure a smooth deployment.
