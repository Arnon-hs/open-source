## 📝 Summary

### English

PaperPilot is a zero‑cloud, pure‑Rust PDF engine with WASM and MCP that enables AI assistants to connect to real tools and data via a standard protocol. To adopt it, deploy an MCP server and link it to your AI agent, then integrate the desired tools. It’s suitable for prototypes and internal workflows, but production use should be preceded by checks on maintenance, documentation, and release cadence.
