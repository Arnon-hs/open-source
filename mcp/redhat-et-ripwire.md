## 📝 Summary

### English

ripwire is a ripgrep‑style tool for AI context that gives coding agents a quick map of any repository. Adopt it by installing the CLI, running the MCP server, and connecting it to your repo so agents can query context via a standard protocol. It’s suitable for prototypes and internal workflows; verify maintenance, licensing, and updates before production use.

### Русский

ripwire — это инструмент, похожий на ripgrep, но для контекста ИИ, который позволяет агентам кода быстро находить и использовать данные из любого репозитория. Чтобы начать, установите CLI, запустите MCP‑сервер и подключите его к вашему репозиторию, после чего агенты смогут обращаться к контексту через стандартный протокол.
