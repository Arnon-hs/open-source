### English

Add Markdown support to macOS QuickLook and Preview so you can instantly view README files and other Markdown documents without extra apps. Install the extension, then open a file in Finder and press ⌥+⌘+Y to see the preview. The project is a prototype; before production use, verify its maintenance status, license, and support.
