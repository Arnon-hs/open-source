## 📝 Summary

### English

Shine is a terminal Markdown previewer and documentation linter that lets you instantly render and validate Markdown files from the command line. Start by running `shine <file>` and configure linting rules via a config file; it integrates easily into CI/CD pipelines. The tool is prototype‑ready, suitable for internal workflows after verifying dependency health and release cadence.
