## 📝 Summary

### English

Ely Office is a Rust‑based office suite built on LibreOfficeKit, offering quick access to LibreOffice features without running the full application. To adopt it, add the crate to Cargo.toml and import the relevant modules, then use the provided APIs for document creation and editing. It is production‑ready for prototypes and internal workflows, though you should verify dependency health, documentation, and release cadence before full deployment.

### Русский

Ely Office – офисный пакет на Rust, построенный поверх LibreOfficeKit, обеспечивает быстрый доступ к функциональности LibreOffice без необходимости запуска полноценного приложения. Для начала интеграции достаточно добавить зависимость в Cargo.toml и подключить нужные модули, после чего можно использовать готовые API для создания и редактирования документов. Пакет считается готовым для прототипов и внутренних рабочих процессов, но перед выпуском в продакшн следует проверить актуальность зависимостей, наличие документации и частоту релизов.
