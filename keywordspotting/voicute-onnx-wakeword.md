# voicute/onnx-wakeword

[![Stars](https://img.shields.io/github/stars/voicute/onnx-wakeword?style=flat-square&color=yellow)](https://github.com/voicute/onnx-wakeword/stargazers) [![Forks](https://img.shields.io/github/forks/voicute/onnx-wakeword?style=flat-square&color=blue)](https://github.com/voicute/onnx-wakeword/network) [![Language](https://img.shields.io/badge/lang-C-informational?style=flat-square)](#) [![Score](https://img.shields.io/badge/score-52%2F100-brightgreen?style=flat-square)](#)

> Offline wake word & keyword spotting engine. One ONNX model detects multiple keywords. ONNX/TFLite, model <130KB, inference <10ms. Runs on Android, ESP32, Linux, Web, and Home Assistant (Wyoming protocol server + HA add-on). No cloud, no data usage.
