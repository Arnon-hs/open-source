## 📝 Summary

### English

Fnmatch-ng is a compact POSIX fnmatch implementation written in a single Zig file, delivering zero‑heap usage and performance comparable to musl. To adopt it, simply include the file in your build and replace the standard fnmatch call, then run tests against your pattern set. It’s suitable for prototypes and internal workflows, but production use should be preceded by a review of maintenance activity and documentation quality.

### Русский

Для практического внедрения достаточно подключить файл в проект и заменить стандартный fnmatch, однако стоит проверить совместимость с вашими шаблонами и провести тесты в целевом окружении.
