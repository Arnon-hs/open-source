## 📝 Summary

### English

PromptLab is a local-first Chrome sidepanel that lets you test and debug LLM prompts directly in your browser, speeding up iteration without leaving the page. To adopt, simply install the extension and link it to your site; you can later hook it into custom scripts via its API. It’s suitable for prototypes and internal workflows, but production use should verify dependency maintenance and release cadence.
