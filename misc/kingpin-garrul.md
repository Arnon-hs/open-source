## 📝 Summary

### English

Garrul is a comments system that runs on a single Cloudflare Worker, enabling you to add discussion functionality to your site with minimal setup. To adopt, clone the repo, configure environment variables, and bind the Worker to your domain; comments will appear instantly. The project is prototype‑ready but should be vetted for dependencies and maintenance before production use.
