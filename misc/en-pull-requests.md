## 📝 Summary

### English

GitHub now supports stacked pull requests, simplifying the management of dependent changes within a single repository. To adopt, create a base PR and then add dependent PRs that automatically update when the base changes. It’s suitable for prototypes and internal workflows, but verify licensing, maintenance, and release cadence before production use.

### Русский

GitHub теперь поддерживает стековые Pull Request, что упрощает управление зависимыми изменениями в одном репозитории. Чтобы начать, создайте основной PR, а затем добавьте зависимые PR, которые автоматически обновятся при изменении базового. Подходит для прототипов и внутренних процессов, но требует проверки лицензии, поддержки и частоты релизов перед продакшн‑использованием.

### 中文
