## 📝 Summary

### English

SimpleWM brings i3-style keybindings to macOS Spaces, giving users a familiar, keyboard‑centric window management experience. Install it via Homebrew, edit the `~/.simplewmrc` config, and launch the daemon—hotkeys are ready to use right away. The tool is prototype‑grade: it receives periodic updates, but you should verify compatibility with your macOS version and test key features before deploying it in production.

### Русский

SimpleWM – это утилита, которая переносит привычные сочетания клавиш i3 в macOS Spaces, позволяя управлять окнами быстрее и привычнее. Чтобы начать использовать, установите пакет через Homebrew, настройте конфигурацию в файле `~/.simplewmrc` и запустите сервис; после этого горячие клавиши работают сразу. Проект находится в стадии прототипа: обновления происходят регулярно, но перед продакшн‑внедрением стоит проверить совместимость с текущей версией macOS и наличие поддержки ключевых функций.

### 中文

SimpleWM 将 i3 的快捷键引入 macOS Spaces，让用户以熟悉的键盘方式管理窗口。只需通过 Homebrew 安装，编辑 `~/.simplewmrc` 配置文件并启动守护进程，热键即可立即生效。该项目处于原型阶段，定期更新，但在正式使用前请确认其与当前 macOS 版本的兼容性并测试核心功能。
