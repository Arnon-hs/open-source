**典型接入方式**  
1. **依赖引入**  
   ```bash
   pip install multi-channel-qr   # 若项目提供 PyPI 包
   # 或者直接克隆源码
   git clone https://github.com/username/multi-channel-qr.git
   cd multi-channel-qr && pip install -e .
   ```
2. **代码示例**（Python）  
   ```python
   from multi_channel_qr import ColorQRGenerator

   # 定义每个通道的原始数据
   channels = {
       "channel_1": "https://example.com/product/123",
       "channel_2": "user_id=456",
       "channel_3": "discount=10%"
   }

   # 生成彩色 QR
   generator = ColorQRGenerator(
       size=400,
       colors=["#ff0000", "#00ff00", "#0000ff"]   # 红、绿、蓝对应三个通道
   )
   img = generator.generate(channels)
   img.save("multi_color_qr.png")
   ```
3. **手动验证**  
   - 使用常见的 QR 码扫描工具（如手机相机、ZXing）分别扫描不同颜色区域，确认每个通道的数据能够被正确解析。  
   - 如需在生产环境中自动化验证，可在 CI 中加入基于 ZXing 的解码脚本，对生成的图片进行批量检查。
