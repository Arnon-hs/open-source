## 📝 Summary

### English

VMMouse for NT 3.x is a mouse integration driver for QEMU/VMware that synchronizes cursor movement between guest and host systems. To adopt it, install the package and enable mouse support in the VM settings, after which the mouse behaves natively. The project is suitable for prototypes and internal workflows, but production use should include checks for dependency maintenance and documentation readiness.
