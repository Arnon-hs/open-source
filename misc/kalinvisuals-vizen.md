## 📝 Summary

### English

Vizen is an open-source tool that creates overlays for Windows, enabling you to crop any window over your game. To adopt it, install the app, select the target window, and enable the overlay via its simple control panel. It’s suitable for prototypes and internal workflows, but production use requires checking dependencies, documentation, and maintenance status.
