## 📝 Summary

### English

CuMetal enables running CUDA programs on Apple Silicon via Metal, giving developers GPU acceleration on macOS without native CUDA support. To adopt, clone the repo, install dependencies, build the library, and link it into your CUDA code. It’s suitable for prototypes and internal workflows, but should be vetted for maintenance and compatibility before production use.
