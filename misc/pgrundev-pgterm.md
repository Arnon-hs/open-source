## 📝 Summary

### English

pgterm is a Go library that simplifies terminal output for PostgreSQL, enabling quick rendering of tables and messages. Adopt it by importing the package into scripts or CLI tools and configuring the output via `pgterm.New`. It’s suitable for prototypes and internal workflows; verify dependency health and maintenance before production use.

### Русский
