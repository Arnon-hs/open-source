## 📝 Summary

### English

Linux2Win automatically detects Linux disks and mounts Ext2/3/4 filesystems as Windows folders, giving users seamless access to Linux data without installing Linux. To adopt, install the package, run `linux2win`, and verify the created directories appear in File Explorer; confirm they reflect the correct contents. The tool is prototype‑grade but stable for internal use; before production, check dependency health and maintenance status.
