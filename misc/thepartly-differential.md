Differential is a TUI diff reviewer that groups changes semantically, making code review faster and clearer. Adopt it by installing the package, running it in a terminal, and pointing it at your repository to view grouped diffs. The tool is in prototype stage, suitable for internal workflows after verifying dependencies and maintenance.
