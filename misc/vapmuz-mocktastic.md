## 📝 Summary

### English

Mocktastic is an Arduino node for Meshtastic, enabling quick integration of a wireless mesh network onto a microcontroller. To adopt it, simply clone the repo, build the firmware, flash it to an Arduino, and connect via BLE to an existing Meshtastic network. The project is prototype‑ready and suitable for internal workflows, though it requires monitoring of dependencies and maintenance before full production use.

### Русский

Mocktastic – это Arduino‑нода для Meshtastic, позволяющая быстро подключить беспроводную сеть к микроконтроллеру. Для начала интеграции достаточно клонировать репозиторий, собрать прошивку и загрузить её на Arduino; далее можно подключить к существующей Meshtastic‑сети через BLE. Проект находится на стадии прототипа, но стабильность достаточна для внутренних рабочих процессов, при условии проверки зависимостей и обновлений.
