### 中文

**项目简介**  
ScriptCat（scriptscat/scriptcat）是一款基于 TypeScript 开发的浏览器扩展，能够在 Chrome、Edge 等 Chromium 系列浏览器中直接运行 Userscript（油猴脚本），为用户提供统一、轻量的脚本管理与执行环境。

**价值**  
- **即插即用**：无需额外的油猴插件，只需安装 ScriptCat 即可加载、启用、禁用用户脚本，降低环境依赖。  
- **安全可控**：提供脚本沙箱、权限声明和细粒度的运行时日志，帮助企业或团队在内部浏览器环境中安全地使用自定义脚本。  
- **开源可审计**：拥有 4.7k+ 星、355 个 fork，活跃维护，代码透明，便于二次定制或与内部工具链集成。

**典型接入方式**  
1. **直接安装**：在 Chrome Web Store（或内部私有扩展仓库）搜索并安装 ScriptCat。  
2. **脚本分发**：将用户脚本放置在公司内部 Git 仓库或 CDN，使用 ScriptCat 的 “远程脚本 URL” 功能自动拉取并更新。  
3. **企业化管理**（可选）：通过组策略或 Chrome 管理控制台统一推送扩展和预配置的脚本列表，实现集中化治理。  

**生产可用性**  
- **活跃度**：最近一次提交于 2026‑07‑05，社区仍在持续贡献 PR 与 Issue。  
- **技术成熟度**：使用 TypeScript 编写，拥有完整的类型定义和 CI 测试，易于二次开发。  
- **安全与合规**：开源许可证为 MIT，代码可自行审计；建议在正式环境前进行一次安全审查（依赖审计、脚本权限评估）。  
- **推荐级别**：在需要统一管理 Userscript 的内部业务系统或研发工具链中，可直接作为生产级解决方案进行小规模试点，随后逐步扩大覆盖范围。
