## 📝 Summary

### English

BeatBox is a cybersecurity lab that runs on your own machine using QEMU and Rust, enabling quick deployment of an isolated environment for vulnerability testing. To adopt it, clone the repo, install QEMU and Rust, then run `cargo run` to spin up the virtual machine. It’s suitable for prototypes and internal workflows, though you should audit dependencies and documentation before production use.
