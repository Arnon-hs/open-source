## 📝 Summary

### English

go-duckfs is a DuckDB virtual file system built on the io/fs interface, enabling seamless integration of DuckDB into any Go application that uses the standard file API. To adopt it, simply import the package and specify a directory path; the driver will automatically translate file operations into database queries. The project is in a prototype stage but stable and maintained, making it suitable for internal workflows after verifying dependencies.

### Русский

Для начала интеграции достаточно импортировать пакет и задать путь к каталогу; готовый драйвер автоматически обрабатывает запросы к файлам.
