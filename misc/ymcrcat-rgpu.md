## 📝 Summary

### English

Rgpu is a PyTorch device that stores tensors on a remote GPU, enabling quick access to remote GPU power without data transfer to the local machine. To adopt it, simply install the package, configure the remote device path, and replace the standard `torch.device` with `rgpu`. It is production‑ready for prototypes and internal workflows, though you should verify dependency support and maintenance before full deployment.

### Русский

Для начала интеграции достаточно добавить пакет в проект, настроить путь к удалённому устройству и заменить стандартный `torch.device` на `rgpu`.
