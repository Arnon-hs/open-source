## 📝 Summary

### English

This project enables seamless switching between a corporate and a personal Mac using a single Apple Magic Keyboard. Adopt it by connecting the keyboard to each machine and configuring macOS profiles. It’s suitable for prototypes, though verify dependencies and documentation before production use.

### Русский

Этот проект помогает переключаться между корпоративным и личным Mac, используя одну клавиатуру Magic Keyboard. Чтобы начать, просто подключите клавиатуру к нужному устройству и настройте профили в macOS. Проект готов к использованию в прототипах, но перед продакшном проверьте актуальность зависимостей и документации.
