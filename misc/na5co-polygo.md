## 📝 Summary

### English

Polygo is a local-first CLI that translates your app’s strings with Ollama, keeping all processing on your machine. To adopt, install Polygo, set up Ollama locally, and run the translate command in your project directory. It’s suitable for prototypes and internal workflows, though you should verify dependencies and maintenance before production use.
