## 📝 Summary

### English

CodeMetrics.CLI delivers code quality metrics for C# projects in VS Code and Visual Studio, enabling quick assessment of style and complexity. Adopt it by installing via NuGet, running the CLI at the project root, and feeding the output into your CI pipeline. It’s production‑ready for prototypes and internal workflows, though you should verify dependency health and documentation before full deployment.

### Русский

CodeMetrics.CLI предоставляет измерения качества кода для проектов C# в VS Code и Visual Studio, помогая быстро оценивать стиль и сложность. Чтобы начать, установите пакет через NuGet, запустите CLI в корне проекта и интегрируйте вывод в CI‑pipeline. Проект считается готовым для прототипов и внутренних процессов, но перед продакшн‑использованием стоит проверить актуальность зависимостей и наличие документации.
