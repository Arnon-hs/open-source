## 📝 Summary

### English

Dudu lets you back up and restore your dev setup on macOS and Linux with a single command, saving time when moving environments. To adopt, install the package, run `dudu backup`, and later `dudu restore` on a new machine. The project is prototype‑ready, with regular updates and dependency checks suitable for internal production use.

### Русский

Dudu позволяет быстро сохранять и восстанавливать настройки разработки на macOS и Linux одной командой, что экономит время при переносе окружения. Чтобы начать использовать, установите пакет, выполните `dudu backup`, а затем `dudu restore` на новом устройстве.
