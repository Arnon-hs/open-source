## 📝 Summary

### English

OpenSign is a free, self‑hosted alternative to DocuSign that lets you quickly set up electronic signatures in your own environment. Start by deploying the container, configuring SMTP and document templates, then integrate the API into your application. It’s suitable for prototypes and internal workflows, but verify dependency maintenance and release cadence before production use.

Для начала интеграции просто разверните контейнер, подключите свой SMTP и настройте шаблоны документов; затем подключите API к вашему приложению.
