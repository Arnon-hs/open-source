## 📝 Summary

### English

Spotnote is a Vite plugin that provides UI feedback from code, streamlining debugging and enhancing user interaction. To adopt it, simply install the package, add it to your Vite config, and tweak settings in spotnote.config.js. It’s suitable for prototypes and internal workflows, though you should verify dependencies and maintenance before production use.

### Русский

Spotnote – это плагин Vite, который позволяет получать UI‑обратную связь от кода, что упрощает отладку и улучшает взаимодействие с пользователем. Для начала интеграции достаточно добавить пакет в проект, подключить его в конфигурацию Vite и настроить параметры в файле spotnote.config.js.
