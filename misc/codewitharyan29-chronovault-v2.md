> A zero-dependency, content-addressable snapshot and recovery engine built from scratch in Python's standard library. Features concurrent-safe snapshots, pack files, tree-diff-derived delta compression, integrity verification, corruption-safe restore, and indexed file history with storage correctness implemented and proven end to end.
