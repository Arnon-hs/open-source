## 📝 Summary

### English

tsrs is a Rust port of the TypeScript 7 type checker, enabling strict type validation within Rust projects. Adopt it by cloning the repo, installing dependencies, and linking the library into your build pipeline while testing compatibility with your codebase. It’s suitable for prototypes and internal workflows, yet production use should be preceded by a review of repository activity and documentation quality.
