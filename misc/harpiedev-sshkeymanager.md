## 📝 Summary

### English

Harpie is a local SSH key manager for Windows that simplifies key storage and management, enhancing your connection security. To adopt it, download the repo, install dependencies, configure via a .harpie.yml file, and then use the keys directly for server access. The project is in a prototype stage but stable and maintained, suitable for internal workflows after verifying license and update cadence.

### Русский

Harpie – это локальный менеджер SSH‑ключей для Windows, который упрощает хранение и управление ключами, повышая безопасность ваших соединений. Чтобы начать использовать, скачайте репозиторий, установите зависимости и настройте конфигурацию через файл .harpie.yml; затем просто подключайтесь к серверам, используя ключи из менеджера. Проект находится в стадии прототипа, но стабильный и поддерживаемый, подходящий для внутренних рабочих процессов после проверки лицензии и обновлений.
