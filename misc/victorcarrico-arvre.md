## 📝 Summary

### English

Arvre is a terminal UI for browsing and managing forks of Claude Code sessions, enabling quick inspection directly from the command line. Install it with `pip install arvre`, run `arvre`, and connect to a session via the CLI. It’s suitable for prototypes and internal workflows; verify dependencies, maintenance, and updates before production use.
