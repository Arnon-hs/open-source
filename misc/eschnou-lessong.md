## 📝 Summary

### English

Lessong turns any song into a language lesson by automatically extracting vocabulary and grammar points. To adopt it, simply add the repository to your CI/CD pipeline and run the provided script to generate lesson content from a chosen track. The tool is suitable for prototypes and internal workflows, though production use requires verifying dependencies and maintenance status.
