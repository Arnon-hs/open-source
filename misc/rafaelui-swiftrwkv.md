## 📝 Summary

### English

The project examines whether a system prompt can be replaced with an initial state in the RWKV-7 model, showing how a pre‑set state can influence outputs. Practically, load the model, set the initial state, swap out the default prompt, and validate in a test environment. It’s suitable for prototypes and internal workflows, but needs manual vetting and maintenance checks before production use.

Для практического применения достаточно загрузить модель, установить начальное состояние и заменить стандартный промпт, после чего проверить результаты в тестовом окружении.
