## 📝 Summary

### English

Gpuix-Svelte is a custom Svelte renderer for GPUI that lets you embed Svelte components directly into GPUI interfaces. To adopt it, clone the repo, install dependencies, and register the renderer in your GPUI configuration, then build Svelte widgets as usual. It’s ready for prototypes and internal workflows, but production use requires verifying dependency health and documentation completeness.

### Русский

Чтобы начать использовать его, сначала клонируйте репозиторий, установите зависимости и подключите рендерер в конфигурации GPUI, после чего можно создавать Svelte‑компоненты как обычные виджеты.
