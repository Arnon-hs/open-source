## 📝 Summary

### English

Purify-edge is a DOMPurify implementation that runs on Cloudflare Workers without jsdom, enabling fast HTML sanitization at the edge. To adopt, install the package, import it into your Worker, and replace the standard DOMPurify calls. It’s suitable for prototypes and internal workflows, but verify dependencies and documentation before production use.
