## 📝 Summary

### English

Astéroric is a lightweight clone of the classic Asteroids arcade game, ported to the Oric-1/Atmos platform using C with inline assembly. You can build and run it in an Oric emulator, then incorporate it into your own workflow after verifying dependencies and compatibility. The project is production‑ready for prototyping, though manual inspection is advised before full deployment.

### Русский

Astéroric — это минималистический клон классической игры Asteroids, адаптированный для платформы Oric-1/Atmos и написанный на C с ассемблерными вставками. Для практического использования его можно собрать и запустить в эмуляторе Oric, а затем интегрировать в собственный проект, проверив совместимость и зависимостями.
