## 📝 Summary

### English

Voicecard is a CLI tool that resolves contradictions in lengthy voice notes, making them easier to process and reuse. To adopt it, clone the repo, install the dependencies, run `voicecard resolve <file>`, and then pipe the cleaned output into your workflow. The project is prototype‑grade: it works well for internal experiments, but you should audit dependencies and documentation before deploying it to production.
