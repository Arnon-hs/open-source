## 📝 Summary

### English

Fundamentalista is a Ruby library that pulls fundamental data of listed companies from SEC EDGAR, enabling quick report generation and financial analysis. To adopt it, add the gem to your Gemfile, run the migration, and configure the API key; then use the provided models to produce reports. It’s suitable for prototypes and internal workflows, but production use should verify dependency health, maintenance, and licensing.
