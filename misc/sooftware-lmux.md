### English

Lmux is a lightweight macOS terminal that lets you run Claude Code and Codex directly from the command line. Install it with Homebrew (`brew install lmux`) and configure `~/.lmuxrc` to connect to your API key. It’s production‑ready for prototypes, though you should audit dependencies and update cadence before full deployment.
