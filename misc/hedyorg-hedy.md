### English

**Project Summary:**

Hedy is an open-source, gradual programming language designed to teach children programming concepts by gradually introducing new language levels with increasing complexity. At its core, Hedy helps children master a subset of syntactically valid Python. This project is a valuable resource for educators and parents seeking to introduce programming concepts to kids.

**Value Proposition:**

Hedy's value proposition lies in its ability to help children develop programming skills in a gradual and accessible way, ultimately preparing them to write Python code. By mastering a subset of Python, kids can transition seamlessly to more advanced programming concepts. This makes Hedy an excellent tool for educational institutions and individuals looking to introduce programming to children.

**Practical Adoption Path:**

To adopt Hedy, educators and parents can start by exploring the language levels, which are designed to be incrementally more complex. This allows kids to build a strong foundation in programming concepts, eventually mastering a subset of Python. The practical adoption path involves:

1. Familiarizing oneself with Hedy's language levels and features.
2. Introducing Hedy to children, starting with the most basic levels.
3. Encouraging kids to build projects and exercises using Hedy.
4. Gradually increasing the complexity of projects as kids progress through the language levels.
