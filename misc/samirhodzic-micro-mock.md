## 📝 Summary

### English

Micro Mock is an instant OpenAPI mock server for VS Code that includes chaos testing. It lets you prototype APIs directly in your editor, but you should manually review it before production use. Start by installing the extension, configuring your OpenAPI spec, and enabling chaos mode to test resilience.

### Русский

Micro Mock – мгновенный мок-сервер OpenAPI в VS Code с поддержкой хаос‑тестирования. Он позволяет быстро прототипировать API, интегрируя его прямо в редактор, но требует ручной проверки перед использованием в продакшене. Для начала подключите расширение, настройте схему OpenAPI и включите режим хаоса, чтобы убедиться в устойчивости вашего кода.
