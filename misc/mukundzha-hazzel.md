## 📝 Summary

### English

Hazzel is a terminal coding agent that supports Bring Your Own Key (BYOK) for LLMs and offers an undo-everything feature, making it useful for reversible AI-assisted coding experiments. To adopt it, clone the repo, configure your API key, and test the undo workflow on a sample project before integrating into real codebases. Production readiness is medium — well-suited for prototypes and internal tools, but verify licensing, maintenance activity, and documentation before broader rollout.

### Русский

Hazzel — терминальный AI-агент для написания кода с возможностью приносить собственные API-ключи (BYOK) и отменять любые изменения. Для интеграции стоит начать с ручной проверки репозитория: установить CLI, подключить провайдер LLM через свои ключи и протестировать undo-механику на изолированном проекте. Готовность к продакшену средняя — подходит для прототипов и внутренних workflow, но требует проверки лицензии, частоты релизов и качества документации перед масштабным использованием.
