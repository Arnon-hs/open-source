## 📝 Summary

### English

yt-audio is a yt-dlp wrapper that lets you download music from YouTube and import it straight into macOS Music. Start by running `yt-audio <URL>`, and the track will be added to your library automatically. It’s ready for prototypes, but verify dependency updates and format support before production use.

### Русский

yt-audio – это оболочка для yt-dlp, позволяющая быстро загружать музыку из YouTube и импортировать её в macOS Music. Для начала используйте команду `yt-audio <URL>`, после чего файл автоматически добавится в библиотеку.
