## 📝 Summary

### English

IguanaTex is a library that converts Markdown projects into LaTeX code, enabling rapid creation of high‑quality PDF documents. To adopt it, add a script to your CI pipeline that transforms Markdown to LaTeX and compiles it into PDF. The project is prototype‑ready, but requires dependency checks before production use.
