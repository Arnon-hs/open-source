## 📝 Summary

### English

Mister Download Manager is an open‑source download manager that closely emulates the interface and user experience of Internet Download Manager, adding BitTorrent support and a browser extension to sniff and capture download links. Built in Rust, it offers high performance and safety, and can be integrated into workflows via its API and command‑line tools. It’s suitable for prototypes and internal use, though production deployment should be preceded by a review of repository activity and documentation.
