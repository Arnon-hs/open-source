## 📝 Summary

### English

Gh-pull is a local GitHub PR dashboard that leverages your existing CLI login, allowing you to view and manage pull requests directly from the terminal without switching to the web interface. To adopt it, simply install the tool and run `gh-pull` to get an interactive list of PRs that can be filtered, commented on, and merged from the command line. It’s production‑ready for prototypes and internal workflows, though you should verify dependency health and maintenance status before full deployment.

Для начала интеграции достаточно установить пакет и выполнить `gh-pull`, после чего вы получите интерактивный список PR, который можно фильтровать и комментировать прямо из терминала.
