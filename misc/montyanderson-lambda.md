## 📝 Summary

### English

Lambda is a fast, portable agent harness written in C that lets you quickly spin up and test custom agents in an isolated environment. To adopt, clone the repo, add it as a submodule, configure via the .ini file, and run the provided tests to verify compatibility with your stack. It’s suitable for prototypes and internal workflows, but you should audit dependencies and maintenance before deploying to production.
