**Project Summary:**
Safe-rm is an open-source project that remaps the `rm` command on Macs to `mv _ Trash`, preventing Large Language Models (LLMs) from accidentally deleting data. This project helps developers add AI capability without starting from a blank model stack, making it ideal for prototyping AI features and building RAG or agent workflows.
