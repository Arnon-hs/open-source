## 📝 Summary

### English

This project shows how to build an incremental archive of Telegram channels using gramjs, crash checkpoints, and a single fetch to two storage backends. To adopt it, integrate gramjs, configure checkpoints, and point to two storage locations, then scale data collection as needed. It’s suitable for prototypes, though you should vet dependencies and maintenance before production use.
