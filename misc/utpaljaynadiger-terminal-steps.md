## 📝 Summary

### English

Terminal Steps is a Claude mod that syncs a daily step goal from Apple Health, letting you track progress straight from the terminal. To adopt it, install the mod, grant Apple Health access, and run the terminal command; it will automatically update the goal and display stats. The project is suitable for prototypes and internal workflows, though production use should verify dependency support and documentation currency.
