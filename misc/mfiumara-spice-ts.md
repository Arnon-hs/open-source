## 📝 Summary

### English

Spice‑ts is a TypeScript‑native SPICE circuit simulator that lets you prototype electronic designs directly in a JavaScript environment. To adopt it, install the npm package, import its API, and describe components and measurements in code, then validate the results in a browser. It’s suitable for internal workflows and prototypes, but production use requires checking dependency health and documentation completeness.
