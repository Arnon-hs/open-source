## 📝 Summary

### English

My Spotify playlist takes pull requests lets you automatically add songs to your Spotify playlist via GitHub pull requests. To adopt, connect your repo to the Spotify API, set up a webhook, and submit a PR describing the track. It’s suitable for prototypes, though you should audit dependencies and maintenance before production use.

### Русский

My Spotify playlist takes pull requests — это инструмент, позволяющий автоматически добавлять песни в ваш плейлист Spotify через GitHub pull request. Чтобы начать, подключите репозиторий к Spotify API, настройте webhook и создайте PR с описанием трека. Проект готов к прототипированию, но требует проверки зависимостей и обновлений перед продакшн‑использованием.
