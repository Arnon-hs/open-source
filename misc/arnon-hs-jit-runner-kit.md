## 📝 Summary

### English

Arnon-hs/jit-runner-kit delivers on‑demand GitHub Actions JIT runners that consume no hosted‑minutes and provision via OpenTofu on Hetzner. To adopt, add the kit to a workflow, run a small proof‑of‑concept, then integrate it into internal CI pipelines.
