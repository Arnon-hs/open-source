## 📝 Summary

### English

Kindred is a self‑hosted personal CRM that stores contacts, tracks interactions, and sets reminders. To adopt it quickly, clone the repo, configure environment variables, and run the Docker container, then import data from CSV or add contacts manually. It’s suitable for prototypes and internal workflows, though you should verify dependencies and maintenance before deploying to production.
