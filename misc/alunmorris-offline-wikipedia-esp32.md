## 📝 Summary

### English

This project is an offline Wikipedia reader for the ESP32 CYD, enabling article viewing without internet access. To adopt it, simply connect the module to an ESP32, flash the firmware, and load the Wikipedia database; it is actively maintained as of 2026‑08‑29, making it suitable for prototypes and internal workflows. Production use should still verify licensing, documentation, and release cadence.
