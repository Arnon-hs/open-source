## 📝 Summary

### English

Tinywm is a scrolling window manager for macOS inspired by Niri, enabling quick window movement and scaling with simple gestures. To adopt it, install via Homebrew, configure `~/.config/tinywm/config.toml`, and launch `tinywm`. Its production readiness is medium—suitable for prototypes and internal workflows, but you should audit dependencies and update cadence before deploying.

### Русский

Tinywm – это скроллирующий менеджер окон для macOS, вдохновленный Niri, который позволяет быстро перемещать и масштабировать окна с помощью простых жестов. Чтобы начать, установите его через Homebrew, настройте конфигурацию в файле `~/.config/tinywm/config.toml` и запустите `tinywm`. Продуктивность умеренная: проект подходит для прототипов и внутренних рабочих процессов, но требует проверки зависимостей и обновлений перед продакшн‑использованием.

### 中文

Tinywm 是受 Niri 启发的 macOS 滚动窗口管理器，支持通过简单手势快速移动和缩放窗口。使用方法：通过 Homebrew 安装，编辑 `~/.config/tinywm/config.toml` 进行配置，然后运行 `tinywm`。其生产就绪度为中等，适合原型和内部工作流程，但在正式使用前需检查依赖和更新频率。
