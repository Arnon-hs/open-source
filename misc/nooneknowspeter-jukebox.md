Jukebox 是一个提供音乐封面艺术风格主题的开源库，灵感来源于各类专辑封面。它通过一组预设的配色、字体和 UI 样式，帮助开发者快速为应用或网站打造富有音乐氛围的视觉效果。

**典型接入方式**  
1. **依赖安装**：`npm i jukebox-themes`（或对应的 Python/Rust 包）。  
2. **加载主题**：在项目入口处引入主题文件，例如 `import { loadTheme } from 'jukebox-themes'; loadTheme('retro‑vinyl');`。  
3. **应用到 UI 框架**：将返回的配色、字体等对象映射到 UI 库（React、Vue、Tailwind、Ant Design 等）的全局样式或主题提供器。
