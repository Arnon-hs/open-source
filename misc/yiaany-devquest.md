### English

**DevQuest: Live GitHub Profile Cards and Daily Repository Battle**

DevQuest is an open-source project that enables developers to add AI capabilities to their workflows without starting from scratch. By providing live GitHub profile cards and a daily repository battle, DevQuest serves as a valuable tool for prototyping AI features, building RAG (Roles, Activities, and Goals) or agent workflows, and evaluating model tooling. With a medium production readiness level, DevQuest is suitable for internal workflows and prototypes, but requires careful dependency and maintenance checks before being used in production.
