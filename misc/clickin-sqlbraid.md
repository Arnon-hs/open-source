## 📝 Summary

### English

SQLBraid lets you write SQL directly in TypeScript, eliminating the need for a query‑builder DSL. To adopt it, simply add the package to your project and replace existing queries with SQL strings wrapped in TypeScript types. It’s suitable for prototypes and internal workflows, though you should audit dependencies and maintenance before deploying it at scale.
