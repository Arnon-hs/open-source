## 📝 Summary

### English

TextoCAD turns text descriptions into editable CAD files (STEP/STL) and runs locally with your key. Start by running the provided script in your local environment, feeding it a text file, and then edit the resulting models in any CAD tool. It’s suitable for prototyping and internal workflows, but production use should include checks for dependency maintenance and documentation.

Для начала используйте готовый скрипт из репозитория, запустив его в локальной среде и импортировав текстовый файл; затем редактируйте полученные модели в любом CAD‑приложении.
