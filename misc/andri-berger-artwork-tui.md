## 📝 Summary

Artwork‑TUI is a terminal-based generative art tool driven by spreadsheets, enabling quick visual pattern creation via an Excel‑like interface. To adopt it, install the package, link it to your CI/CD pipeline, and configure CSV templates, after which rendering runs automatically. The project is prototype‑ready, with regular updates and documentation, making it suitable for internal workflows once dependencies and licensing are verified.
