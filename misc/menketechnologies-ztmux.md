## 📝 Summary

### English

Ztmux is a Rust-based superset of tmux designed for daily use, adding advanced features to the familiar terminal multiplexer. To adopt it, install via Cargo, point your .tmux.conf to the new binary, and replace the default tmux command. The project is in a prototype stage, so verify dependencies and update cadence before deploying it in production.

### Русский

Чтобы начать, установите пакет через Cargo, сконфигурируйте его в файле .tmux.conf и замените стандартный tmux на Ztmux.
