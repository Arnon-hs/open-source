## 📝 Summary

### English

Botspot/pi-apps is a web‑based storefront that lets Raspberry Pi users discover, browse, and install open‑source applications directly on their devices. Built with a modern frontend stack, it aggregates projects from various repositories, provides searchable categories and detailed app metadata, and streamlines the installation process with one‑click deployment on the Pi.

### Русский

Botspot/pi-apps — это открытый каталог приложений для Raspberry Pi, позволяющий легко находить, устанавливать и обновлять open‑source проекты прямо на устройстве. Интуитивный веб‑интерфейс (Frontend) предоставляет пользователям удобный поиск, фильтрацию и подробные описания приложений, ускоряя процесс развертывания и экспериментов с Pi‑экосистемой. Проект поддерживает автоматическое построение пакетов и интеграцию с репозиториями, делая Raspberry Pi настоящим магазином свободного программного обеспечения.
