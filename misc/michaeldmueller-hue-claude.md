## 📝 Summary

### English

This project lets Philips Hue lights flash when Claude finishes a turn or requests permission, providing a visual cue for interaction status. To adopt it, connect the Hue API to your Claude bot and set triggers on turn‑completion and permission‑request events. It’s suitable for prototyping, but you should audit dependencies and maintenance before deploying to production.
