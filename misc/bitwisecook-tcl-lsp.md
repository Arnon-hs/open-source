### English

This project offers an LSP for Tcl 8.4‑9.1, F5 iRules, F5 iApps, and other Tcl dialects, simplifying code completion and static analysis. To adopt it, install the extension in VS Code, link it to your project, and configure the Tcl interpreter path. It is suitable for prototypes and internal workflows, but production use should be preceded by a review of repository activity and dependency maintenance.
