## 📝 Summary

### English

OSHintosh is an open‑source hardware project that recreates a 68000 Macintosh with a bootable ROM disk, enabling classic Mac functionality without original hardware. Adoption involves connecting a 68000‑compatible controller, loading the ROM disk image, and running the system; community support exists but manual compatibility checks are advised. It’s suitable for prototypes and internal workflows, though production use requires verifying licenses, documentation, and release cadence.
