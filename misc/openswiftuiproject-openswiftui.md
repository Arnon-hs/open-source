## 📝 Summary

### English

OpenSwiftUI is an open‑source reimplementation of Apple’s SwiftUI, enabling rapid UI prototyping without relying on proprietary SDKs. Start by adding it via Swift Package Manager and swapping out standard SwiftUI components for OpenSwiftUI equivalents, verifying compatibility with your codebase. It’s suitable for prototypes and internal workflows, but should be vetted for dependencies and maintenance before production use.

### Русский

OpenSwiftUI — открытая реализация SwiftUI от Apple, позволяющая быстро прототипировать пользовательские интерфейсы без использования проприетарного SDK. Для начала интегрируйте библиотеку через Swift Package Manager, затем замените стандартные SwiftUI‑компоненты на OpenSwiftUI‑эквиваленты, проверив совместимость с вашим проектом. Проект подходит для прототипов и внутренних процессов, но требует проверки зависимостей и поддержки перед выпуском в продакшн.
