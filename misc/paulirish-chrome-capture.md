## 📝 Summary

### English

Chrome 153 now includes a native MP4 tab recorder, enabling quick video capture of the active browser tab without external extensions. Start by selecting Tools → Record Tab and save the resulting MP4 file to your desired location. The feature is prototype‑ready: updates are frequent, but you should verify compatibility with your scripts and dependencies before deploying it to production.

### Русский

Chrome 153 добавил встроенный MP4‑рекордер вкладки, что позволяет быстро записывать видео с активного окна браузера без сторонних расширений. Для начала используйте меню «Инструменты» → «Запись вкладки», а затем сохраните файл MP4 в нужную папку. Проект находится в стадии прототипа: обновления происходят регулярно, но перед выпуском в продакшн стоит проверить совместимость с вашими скриптами и зависимостями.
