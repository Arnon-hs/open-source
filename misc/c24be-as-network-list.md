## 📝 Summary

### English

C24Be/AS_Network_List is an open‑source tool that automatically generates blacklists of IP subnets associated with Russian government agencies. By fetching and processing authoritative routing data, it creates up‑to‑date network lists that can be integrated into firewalls, proxies, or other server‑side security solutions to block traffic from these entities. The project is focused on backend integration and aims to simplify the deployment of region‑specific network blocks.

### Русский

C24Be/AS_Network_List — это открытый backend‑инструмент, автоматически генерирующий черные списки подсетей, принадлежащих российским государственным структурам, для их блокировки на серверах. Проект собирает актуальные данные об автономных системах (AS) и преобразует их в удобные форматы (IP‑range, CIDR, hosts‑file), позволяя быстро интегрировать блокировку в любые сетевые решения. Он ориентирован на администраторов, желающих обеспечить фильтрацию трафика от государственных ресурсов.
