## 📝 Summary

### English

The ECMAScript ShadowRealm API spec offers isolated execution contexts, enabling safe script runs without affecting the global object. To adopt it, simply include a polyfill, instantiate `new ShadowRealm()`, and execute scripts within that realm. The project is suitable for prototypes and internal workflows, though production use should involve a review of dependencies and documentation.

### Русский

ECMAScript‑спецификация ShadowRealm API предоставляет изолированные контексты выполнения, позволяя безопасно запускать скрипты без влияния на глобальный объект. Для практического внедрения достаточно подключить polyfill и использовать `new ShadowRealm()` в вашем коде, после чего можно выполнять скрипты в изоляции. Проект готов к прототипированию и внутреннему использованию, но перед выпуском в продакшн рекомендуется проверить актуальность зависимостей и наличие документации.
