**价值**

Neo4j Spark 连接器帮助团队重用服务基础设施，而不是重建常见的后端组件。它可以帮助团队:

* 快速部署 API 服务
* 重用后端基础设施
* 标准化服务模式

**典型接入方式**

Neo4j Spark 连接器的接入方式如下：

1. 在你的 Spark 项目中添加 Neo4j Spark 连接器依赖。
2. 使用 Spark 的 DataSource API 来读写 Neo4j 数据库。
