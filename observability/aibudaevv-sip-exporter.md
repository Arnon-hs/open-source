The Sip-exporter project is an open-source tool that uses eBPF (extended Berkeley Packet Filter) technology to provide passive monitoring of SIP/RTP (Session Initiation Protocol/Real-time Transport Protocol) traffic, making it easier to inspect and debug production behavior. This tool can be integrated with Prometheus for further analysis and tracking of service health.
