> Five Claude Code plugins, Python stdlib + git. ar-board: judge agent proposals one by one on a local board; the agent keeps your reasons. publish-check: scan a repo's history for personal data before it goes public. tidy-board: delete stale branches, worktrees, and stashes only on approval. Plus doc, handoff, and TODO tools, and a status line.
