### 中文

**项目简介**  
uswds/uswds-site 是美国联邦政府的官方网页设计系统（U.S. Web Design System）文档站点，提供统一的 UI 规范、组件库和实现指南，帮助政府机构快速搭建符合可访问性和品牌要求的网页。

**价值**  
- **统一规范**：通过统一的设计语言和可复用组件，显著降低跨部门前端开发的维护成本。  
- **可访问性**：所有组件均遵循 WCAG 2.1 标准，帮助项目满足严格的可访问性要求。  
- **AI 扩展入口**：站点本身是静态 HTML，可在其基础上快速嵌入 AI 功能（如聊天机器人、内容检索或 RAG），无需从零构建模型堆栈。

**典型接入方式**  
1. **Fork / Clone**：先 fork 项目或直接 clone 到本地。  
2. **本地构建**：使用 Node.js + npm（或 Yarn）运行 `npm install && npm start`，在本地预览文档站点。  
3. **嵌入 AI**：在需要的页面或组件中加入前端 SDK（如 OpenAI、Anthropic、LangChain）或后端 API，利用站点的静态页面作为 UI 容器，快速实现原型。  
4. **CI/CD 部署**：通过 GitHub Actions、Netlify、Vercel 等平台自动化构建并发布到 GitHub Pages 或自有域名。  

**生产可用性**
