### English

The sveltejs/eslint-plugin-svelte delivers an ESLint plugin that uses the Svelte AST to catch Svelte‑specific bugs and style issues, helping engineers save time during development, code review, and CI feedback. Adoption is straightforward: install the package, add it to your ESLint configuration, and extend the recommended rule set with little to no extra setup.
