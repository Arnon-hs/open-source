### 中文

**简短介绍**  
HACS (integration) 为 Home Assistant 提供了功能强大的可视化界面，让用户可以轻松管理和下载所有自定义组件、插件和主题。它通过统一的 UI 把繁琐的手动安装过程自动化，极大提升前端交付效率。

**价值**  
- **降低 UI 开发成本**：提供即插即用的界面组件，开发者无需从头编写复杂的前端页面。  
- **加速产品 UI 上线**：复用成熟的 HACS 交互模式，快速构建产品设置页、插件市场等用户界面。  
- **提升前端交付质量**：统一的下载、更新、版本管理流程，减少因手工操作导致的错误和不一致。

**典型接入方式**  
1. **准备环境**：在 Home Assistant 实例中启用 HACS 集成（通过官方文档的“一键安装脚本”或手动添加 `custom_components/hacs` 目录）。  
2. **配置 API Token**：在 Home Assistant UI 中生成 HACS Token 并在 `configuration.yaml` 中声明。  
3. **添加自定义仓库**：使用 HACS UI 添加自定义 GitHub 仓库（如 `hacs/integration`），即可在前端看到对应的插件/组件列表。  
4. **前端调用**：在自己的 Lovelace 页面或自定义面板中，通过 HACS 提供的 JavaScript/REST 接口获取已安装组件信息，实现“一键安装”“检查更新”等交互。  
5. **小范围验证**：先在测试环境部署一个最小的 Proof‑of‑Concept（例如仅展示插件列表），确认 README、依赖和权限无误后再推广到生产。
