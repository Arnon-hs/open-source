### 中文

**项目简介**  
pythonnative（pythonnative/pythonnative）是一套开源工具链，能够让开发者使用纯 Python 代码直接生成原生 Android 与 iOS 应用。它通过封装平台 SDK、提供 CLI 与 API，省去繁琐的 UI 框架移植工作，让 Python 开发者也能快速交付面向用户的移动界面。

**价值**  
- **降低 UI 开发成本**：无需手写 Java/Kotlin 或 Swift/Objective‑C，只需编写 Python 即可生成完整的原生界面。  
- **组件复用**：一次编写的 UI 组件可在 Android 与 iOS 上共享，显著提升前端交付速度。  
- **加速产品迭代**：业务逻辑仍然使用熟悉的 Python 生态（如 Flask、FastAPI），前后端统一语言，迭代周期更短。

**典型接入方式**  
1. **CLI 安装**：`pip install pythonnative` 后使用 `pn build`、`pn run` 等命令生成对应平台的项目结构。  
2. **SDK 集成**：在 Python 项目中引入 `import pythonnative as pn`，调用 `pn.create_app(...)`、`pn.add_screen(...)` 等 API 动态构建 UI。  
3. **CI/CD 流程**：在构建脚本中加入 `pn build --platform android|ios`，产出 `.apk` 或 `.ipa` 包，交由常规移动发布流水线。

**生产可用性**  
- **活跃度**：最近一次提交于 2026‑07‑11，项目仍在维护；GitHub 101 星、1 个 fork，社区关注度适中。  
- **技术成熟度**：提供完整的 API、CLI 与平台 SDK，已支持主流 Android (API 21+) 与 iOS (13+) 版本。  
- **风险**：目前需进一步审查许可证兼容性、依赖安全（尤其是打包的原生库）以及维护者的长期可用性。总体来看，项目已具备在内部或受控环境下进行试点的条件，若通过安全与合规审查，可考虑在生产环境中正式使用。
