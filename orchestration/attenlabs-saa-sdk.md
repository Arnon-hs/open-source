### English

**Project Summary:**
attenlabs/saa-sdk is an open-source project that provides addressable detection for voice agents, enabling device-directed speech detection that runs before speech-to-text (STT) processing. This layer helps prevent background speech, side conversations, and TTS echo from triggering the voice agent, making it a crucial addition to various workflows. With its model-agnostic and drop-in compatibility with popular platforms, it streamlines the development of voice agents and multi-agent workflows.

**Value Proposition:**
The attenlabs/saa-sdk offers significant value by helping developers turn isolated prompts and tools into repeatable agent workflows.
