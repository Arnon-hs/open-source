The gamedev-skills/awesome-gamedev-agent-skills project is an open-source framework that enables game developers to create repeatable workflows for AI coding agents. This project provides 66 original, version-pinned skills in a portable format that can be used across various AI coding agents and game engines.

The value proposition of this project lies in its ability to turn isolated prompts and tools into repeatable agent workflows.
