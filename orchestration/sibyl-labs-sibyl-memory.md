### English

**Project Summary:**

Sibyl-Memory is an open-source, file-based long-term memory solution for AI agents, designed to enable repeatable agent workflows by coordinating multi-agent tasks, adding tool-use pipelines, and standardizing agent memory. This durable memory system is composed of five plugins, including an SDK, CLI, MCP server, Hermes adapter, and LangGraph BaseStore. With its high production readiness, Sibyl-Memory is suitable for serious pilots and has a strong ecosystem signal.

**Value Proposition:**
The primary value proposition of Sibyl-Memory lies in its ability to transform isolated prompts and tools into repeatable agent workflows. By providing a durable, file-based long-term memory solution, Sibyl-Memory enables AI agents to learn from past experiences, adapt to new situations, and perform complex tasks more efficiently.
