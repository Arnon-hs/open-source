## 📝 Summary

### English

**Summary:**
The Microsoft Skill Recorder is an open-source desktop application that records on-screen work sessions and reconstructs them as reusable Skills or Automations for Microsoft Scout, Copilot Cowork, or Copilot Studio. This tool helps turn isolated prompts and tools into repeatable agent workflows, enabling users to coordinate multi-agent workflows, add tool-use pipelines, and standardize agent memory. With its high production readiness and strong ecosystem signals, the Skill Recorder is a promising candidate for serious piloting.

**Value:**
The Microsoft Skill Recorder offers significant value by providing a seamless way to record and reconstruct on-screen work sessions, making it easier to create reusable Skills or Automations. This tool helps users streamline their workflows, improve productivity, and reduce manual effort. By standardizing agent memory and adding tool-use pipelines, users can create more efficient and effective multi-agent workflows.

**Practical Adoption Path:**
To adopt the Microsoft Skill Recorder, users can follow these steps:

1. Install the desktop application and familiarize themselves with its features.
2. Record on-screen work sessions to capture the desired workflow.
3. Use the GitHub Copilot CLI to reconstruct the recorded session as an intent + ordered steps.
4. Build a reusable Skill or Automation for Microsoft Scout, Copilot Cowork, or Copilot
