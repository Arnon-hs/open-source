### 中文

**简短介绍**  
PaperQuay 是一款面向桌面用户的文献管理工具，专注于 PDF 阅读、翻译、论文概览以及 AI 代理工作流的统一管理。它能够把零散的 Prompt 与工具封装成可复用的多代理流水线，让科研与工程团队更高效地协同处理文献。

**价值**  
- **工作流自动化**：将独立的翻译、摘要、引用检索等功能组合成可重复执行的 AI 代理流程，避免手动切换工具。  
- **多代理协同**：支持在同一项目中调度多个 AI 代理，统一管理它们的记忆与状态，提升信息一致性。  
- **桌面优先体验**：基于 TypeScript/Electron 实现，界面流畅、快捷键丰富，适合科研人员的日常使用。

**典型接入方式**  
1. **快速 POC**：克隆仓库后运行 `npm install && npm run dev`，确认 README 中的启动步骤即可得到本地可用的演示环境。  
2. **API/插件集成**：通过项目提供的 `agent-pipeline` 模块，将自定义的 Prompt、工具函数（如翻译 API、文献检索）注册到工作流中；在业务系统中以 Node.js 包的形式 `npm i paperquay` 引入即可。  
3. **CI/CD 自动化**：将 `paperquay-cli` 脚本嵌入构建流水线，实现文献批量处理（如自动生成摘要、翻译并存档），配合企业内部的文献库即可形成闭环。

**生产可用性**
