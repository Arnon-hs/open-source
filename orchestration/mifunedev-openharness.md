mifunedev/openharness 是一个面向 AI/ML 与 DevOps 场景的开源编排框架，提供「Sandbox」环境让用户自行定义「Harness」——即将孤立的 Prompt、工具或模型封装成可重复、可组合的智能体工作流。  

**核心价值**  
- **工作流标准化**：把零散的 Prompt 与工具统一抽象为 Agent，支持记忆、状态管理和跨 Agent 的信息流。  
- **多 Agent 编排**：天然支持多智能体协同、工具调用链路以及条件分支，适用于复杂的业务流程自动化。  
- **即插即用**：通过统一的 API/SDK/CLI，开发者可以快速将已有的模型或工具接入，无需重写业务逻辑。

**典型接入方式**  
1. **API**：调用 RESTful 接口创建、启动、监控 Agent 工作流。  
2. **SDK**：使用 TypeScript/JavaScript SDK 在代码中直接构建 `Harness`，配置 Prompt、工具、记忆模块等。  
3. **CLI**：通过命令行工具本地调试或在 CI/CD 中自动化部署工作流。  
4. **语言元数据**：项目自带的 `package.json`、`tsconfig` 等元信息，可帮助 IDE 自动补全和类型检查，加速开发。
