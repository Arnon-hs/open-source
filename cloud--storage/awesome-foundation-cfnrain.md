## 📝 Summary

### English

Cfnrain is a community fork that revives AWS's archived CloudFormation CLI, offering an updated tool for generating CloudFormation templates. To adopt it, clone the repo, install dependencies, run `cfnrain init`, and then weave it into your CI/CD pipeline. It’s suitable for prototypes and internal workflows, though you should verify repository activity, licensing, and SDK compatibility before deploying it to production.
