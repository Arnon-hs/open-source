## 📝 Summary

### English

ILrDOS is a header‑only C++20 robot runtime tailored for the Raspberry Pi Zero 2 W, enabling rapid prototyping of autonomous devices without extra library installs. To adopt it, simply include the headers in your project and enable the desired modules, then leverage the built‑in components for sensor and actuator control. With regular updates and modern C++ support, it’s suitable for prototypes and internal workflows, though production use should verify dependency compatibility and documentation completeness.
