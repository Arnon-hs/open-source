## 📝 Summary

### English

Hyper64 is a high‑performance AVX‑512 Base64 engine written in Rust that delivers 10‑25 GB/s, ideal for encoding and decoding large data streams. Adoption is straightforward: add the crate to Cargo.toml and replace standard Base64 calls with Hyper64, ensuring the target CPU supports AVX‑512. The library is prototype‑grade; production use requires vetting dependencies, documentation, and release stability.

### Русский
