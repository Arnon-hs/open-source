## 📝 Summary

### English

Doh-proxy is a lightweight DNS‑over‑HTTPS proxy written in Go that enables secure DNS resolution in corporate environments. To adopt it, deploy the container, point it to a DoH server, and configure local clients to use the proxy; then monitor performance and update dependencies as needed. It is suitable for prototypes and internal workflows, but should be vetted for maintenance and dependency health before production use.
