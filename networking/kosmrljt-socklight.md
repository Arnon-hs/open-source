## 📝 Summary

### English

SockLight is a SOCKS5 dev proxy featuring a live terminal dashboard that lets you monitor and debug traffic in real time. To adopt it, simply add the repository to your Docker‑compose setup and point your services to the proxy; the dashboard will automatically display active connections. It’s suitable for prototypes and internal workflows, though you should verify dependencies and documentation before deploying to production.
