## 📝 Summary

### English

LeanHTTP is an HTTP client for Lean 4 that lets you quickly integrate external web services into Lean projects. Start by adding the dependency via `leanpkg add` and following the README examples for simple GET/POST requests. It’s suitable for prototypes and internal workflows, but verify dependency health and open issues before production use.
