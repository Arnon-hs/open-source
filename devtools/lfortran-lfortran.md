## 📝 Summary

### English

LFortran is an open‑source modern Fortran compiler that aims to provide a fast, interactive, and extensible development experience. It supports the latest Fortran standards, offers Python‑like scripting for metaprogramming, and integrates with AI/ML workflows through easy interfacing with scientific Python libraries. The project serves as the primary repository for contributors and users to build, test, and extend the compiler’s capabilities.

### Русский

LFortran — это открытый компилятор Fortran, разработанный для современной научной и инженерной вычислительной среды. Он обеспечивает быстрый и корректный перевод кода Fortran в оптимизированный LLVM‑IR, поддерживая как традиционный Fortran 77/90, так и новейшие стандарты, а также предоставляет возможности интеграции с инструментами искусственного интеллекта и машинного обучения. Проект активно развивается в рамках сообщества open‑source и доступен на GitHub в репозитории **lfortran/lfortran**.
