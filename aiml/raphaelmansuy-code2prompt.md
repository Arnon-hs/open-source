### English

**Project Summary:**
Code2Prompt is an open-source command-line tool that helps developers provide context to Large Language Models (LLMs) by generating a comprehensive Markdown file containing their codebase's content. This tool simplifies the process of integrating AI capabilities into existing projects. By using Code2Prompt, developers can easily prototype AI features, build Retrieval-Augmented Generation (RAG) or agent workflows, and evaluate model tooling.

**Value:**
The value proposition of Code2Prompt lies in its ability to add AI capability to existing projects without requiring developers to start from a blank model stack. This tool saves time and effort by automating the process of providing context to LLMs, allowing developers to focus on building and evaluating AI features.

**Practical Adoption Path:**
The practical adoption path for Code2Prompt involves the following steps:

1. **Installation**: Developers can install Code2Prompt using pip or by cloning the repository from GitHub.
2. **Usage**: Users can run the tool from the command line, providing the path to their codebase as input.
3. **Configuration**: The tool generates a Markdown file containing the codebase's content, which can be used to provide context to LLMs.
