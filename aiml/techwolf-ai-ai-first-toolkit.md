### 中文

**项目简介**  
techwolf‑ai/ai‑first‑toolkit 是一套开源的 Claude Code 与 Codex 能力集合，旨在帮助开发者在现有项目中快速引入 AI 功能。它遵循 AI‑first 设计原则，提供审计、重构和快速启动的工具链，让项目能够在不从零搭建模型栈的前提下，实现 AI 驱动的原型、RAG/Agent 工作流以及模型工具评估。

**价值**  
- **即插即用**：通过封装好的 API/SDK/CLI，开发者只需少量代码即可为产品或服务添加自然语言理解、代码生成等 AI 能力。  
- **降低门槛**：无需自行训练或部署大型模型，直接复用 Claude Code / Codex 的成熟实现，显著缩短研发周期。  
- **AI‑first 设计**：提供审计与重构工具，帮助团队在项目全生命周期中贯彻 AI‑first 思维，提升系统可维护性与可扩展性。

**典型接入方式**  
1. **API/SDK**：在 TypeScript 项目中通过 `npm install @techwolf/ai-first-toolkit` 引入 SDK，调用 `auditProject()、bootstrapFeature()` 等高层函数即可。  
2. **CLI**：使用 `npx ai-first-toolkit audit <path>`、`npx ai-first-toolkit bootstrap --type=rAG` 等命令行工具，对本地代码库进行快速审计或生成模板代码。  
3. **语言元数据**：工具会自动读取项目的 `package.json`、`tsconfig.json` 等元信息，生成对应的 AI 接入配置，免去手动编写配置文件的步骤。

- **活跃度**：最近一次提交于 2026‑07‑09，仓库拥有 90+ 星、2 个 Fork，且在多个话题（11 个）下被引用，表明社区关注度和活跃度较高。  
- **技术成熟度**：核心实现基于 TypeScript，提供完整的类型定义，易于在现代前端/后端项目中集成。
