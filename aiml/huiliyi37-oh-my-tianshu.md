### English

**Project Summary:**

Oh My Tianshu is a fully open-source coding agent built on top of the DSH Harness, offering a comprehensive set of features including visual interface, cross-session memory, validation gates, agent routing, semantic and graph code search, file rollback, and full-screen terminal UI. It is a friendly MIT fork of DeepSeek Harness, maintaining the upstream architecture of plugin-based components. Oh My Tianshu aims to add AI capabilities without requiring a blank model stack.

**Value Proposition:**

The value proposition of Oh My Tianshu lies in its ability to enhance coding capabilities with AI features, making it easier to prototype and build AI-powered workflows. It supports the development of RAG (Retrieval-Augmented Generation) or agent workflows, allowing users to evaluate and refine model tooling.
