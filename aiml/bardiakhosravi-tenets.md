## 📝 Summary

### English

**Project Summary:**

Tenets is an open-source context framework designed to empower AI coding agents, such as Cursor, Claude Code, and Windsurf, to build backend services using Domain-Driven Design (DDD) and Hexagonal Architecture. This framework streamlines the development process, allowing users to add AI capabilities without starting from scratch. It is suitable for prototyping AI features, building RAG (Risk, Action, and Goal) or agent workflows, and evaluating model tooling.

**Value:**

The primary value proposition of Tenets lies in its ability to simplify the integration of AI capabilities into existing projects. By providing a pre-built framework, users can focus on building and refining their AI models, rather than investing time and resources into setting up a new model stack.

**Practical Adoption Path:**

To adopt Tenets, users can follow these steps:

1. Start with a small proof of concept to evaluate the framework's feasibility.
2. Review the README documentation to understand the framework's architecture and usage.
3. Choose an AI coding agent (Cursor, Claude Code, or Windsurf) to integrate with Tenets.
4. Develop and refine AI models using the Tenets framework.
5. Integrate the AI-powered backend service into the existing application.
