### English

**Project Summary:**
Greenfield is an open-source Claude Code plugin that uses AI to reverse-engineer clean behavioral specs, test vectors, and acceptance criteria from any codebase. This allows a fresh team to reimplement a project without inheriting the original's internal structure, making it easier to adopt AI capabilities without starting from scratch. By providing a provenance trail, Greenfield enables teams to evaluate model tooling and build RAG or agent workflows.

**Value:**
The value proposition of Greenfield lies in its ability to add AI capability without requiring a team to start from a blank model stack. This is particularly useful for prototyping AI features, building RAG or agent workflows, and evaluating model tooling.
