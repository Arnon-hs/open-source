## 📝 Summary

### English

**Project Summary:**

OpenCode Mobile is an open-source Android client for the OpenCode AI coding agent, allowing users to run AI coding sessions on their phone against a self-hosted server over Tailscale. This project provides a valuable tool for developers to add AI capability without building a custom model stack, making it suitable for prototyping AI features and building RAG or agent workflows. With its straightforward integration and medium production readiness, OpenCode Mobile is ideal for internal workflows and testing purposes.

**Value:**

The primary value proposition of OpenCode Mobile lies in its ability to enable developers to integrate AI capabilities into their projects without starting from scratch. By leveraging a self-hosted AI coding agent, users can focus on building and testing their applications without worrying about the underlying model stack.

**Practical Adoption Path:**

To adopt OpenCode Mobile, developers can follow these steps:

1. Install the F-Droid client on their Android device.
2. Clone the OpenCode Mobile repository and build the project.
3. Set up a self-hosted server using Tailscale for secure communication.
4. Integrate the OpenCode Mobile client with the self-hosted server.
5. Use the client to run AI coding sessions and test its functionality.
