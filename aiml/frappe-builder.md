### 中文

**项目简介（2‑3 句）**  
frappe/builder 是一款基于 Vue 的可视化网页构建工具，用户可以拖拽组件快速搭建精美站点并实现“一键发布”。它内置 AI 能力模块，帮助开发者在无需从零搭建模型堆栈的情况下，直接在页面中嵌入 RAG、智能代理等 AI 工作流。

**价值**  
- **快速原型**：通过直观的可视化编辑器，业务方和前端团队可以在数分钟完成页面和 AI 功能的原型验证。  
- **即插即用的 AI**：提供预置的模型调用、向量检索和 Agent 编排接口，省去模型部署、环境配置等繁琐步骤。  
- **统一前端生态**：基于 Vue，易于与现有前端项目集成，保持代码风格和组件复用。

**典型接入方式**  
1. **阅读 README**：确认项目依赖（Node、Vue CLI）并执行 `npm install`。  
2. **小型 POC**：在本地创建一个空的 Vue 项目，使用 `npm link frappe/builder`（或直接 `npm i frappe/builder`）引入组件库。  
3. **AI 模块配置**：在 `.env` 或配置文件中填入所使用的模型 API 密钥（如 OpenAI、Claude 等），并在页面中挂载 `AIBlock`、`RAGPanel` 等组件。  
4. **部署测试**：使用 `npm run build && npm run serve` 验证页面渲染与 AI 调用是否正常，然后逐步迁移到 CI/CD 流程中。
