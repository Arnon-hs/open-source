## 📝 Summary

### English

**Summary:**
The AWS Serverless Application Model (AWS SAM) is an open-source project that enables teams to reuse backend infrastructure by transforming SAM templates into CloudFormation templates. This model helps teams ship API services faster, reuse backend infrastructure, and standardize service patterns. With over 9,560 GitHub stars and recent activity, AWS SAM is a highly production-ready solution for teams looking to streamline their backend development.

**Value:**
The primary value proposition of AWS SAM lies in its ability to help teams reuse service infrastructure, reducing the time and effort required to build and maintain backend components. By standardizing service patterns, teams can improve consistency and efficiency across their applications.

**Practical Adoption Path:**
To adopt AWS SAM, teams can follow these steps:

1. **Familiarize yourself with SAM**: Learn about the AWS Serverless Application Model and its benefits.
2. **Choose a SAM template**: Select a suitable SAM template for your use case and modify it as needed.
3. **Transform the template**: Use the AWS SAM transform to convert the SAM template into a CloudFormation template.
4. **Deploy and test**: Deploy the transformed template to your AWS environment and test your application.
