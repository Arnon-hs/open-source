## 📝 Summary

### English

DearSQL is a native C++ database client built with Dear ImGui that lets teams persist, query, and move data without custom plumbing. To adopt it, simply add the library to your project, link the appropriate database driver, and use the ready‑made widgets for table operations. It’s suitable for prototypes and internal workflows, though you should verify dependencies and maintenance before production use.
