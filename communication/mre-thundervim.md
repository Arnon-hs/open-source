## 📝 Summary

### English

Thundervim brings familiar Vim keybindings to Thunderbird’s compose window, enabling fast text editing without changing keyboard layouts. Install the extension, configure your .vimrc, and start using standard Vim commands right away. The project is prototype‑ready and stable, making it suitable for internal workflows.

### Русский

Thundervim добавляет привычные клавиши Vim в окно создания письма Thunderbird, позволяя быстро редактировать текст без переключения клавиатурных раскладок. Для начала используйте установку расширения и настройку .vimrc, после чего можно сразу применять привычные команды.
