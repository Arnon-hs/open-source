## 📝 Summary

### English

The Raspberry Pi Pico W Irrigation project integrates irrigation control via Telegram and Google Calendar, enabling users to schedule and monitor watering from a single microcontroller. Implementation involves connecting the Pico to Wi‑Fi, setting up a Telegram bot, and syncing the calendar, after which pumps can run automatically on a timetable. It is suitable for prototypes and internal workflows, but production use should verify dependency maintenance and documentation support.

Для внедрения достаточно подключить Pico к Wi‑Fi, настроить бота Telegram и синхронизировать календарь, после чего можно автоматически запускать насосы по расписанию.
