## 📝 Summary

### English

WhiteTowerAI/cut-as-code is an AI‑powered tool that automates short‑form vertical video creation, enabling quick production of Shorts/Reels clips and conversion of long videos into 9:16 assets with auto‑captions and clipping. Adopting it is straightforward: install the Python SDK, configure API credentials, and run the provided scripts to generate ready‑to‑publish clips. The project is production‑ready for prototypes and internal workflows, though a final check of dependencies and security updates is advised before full deployment.
