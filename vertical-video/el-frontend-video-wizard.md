## 📝 Summary

### English

el-frontend/video-wizard is an open‑source toolkit that automates short vertical video production using GPT‑4o to find viral clips, Whisper for subtitles, and Remotion for rendering. Its FastAPI backend and Docker readiness make it easy to integrate into existing pipelines, while PostgreSQL support ensures production‑grade data handling.
