## 📝 Summary

### English

Reel‑Kit is an automated vertical‑video production platform that combines a UI studio, a CLI tool, 20 hand‑drawn templates, and a local TTS engine. To adopt it quickly, clone the repo, run the CLI to slice long videos into 9:16 clips, tweak the templates for your brand, and publish the finished reels directly to Shorts/Reels. The project is production‑ready with frequent updates, active community support, and easy CI/CD integration.

### Русский

Reel‑Kit — это автоматизированная платформа для создания вертикальных видео, объединяющая UI‑рабочую станцию, CLI‑инструмент, набор 20 стилизованных шаблонов и локальный TTS‑двигатель. Чтобы быстро применить её, просто подключите репозиторий, запустите CLI для генерации клипов из длинных видео и настройте шаблоны под свой бренд; готовые клипы сразу готовы к публикации в Shorts/Reels. Пакет считается готовым к продакшн‑использованию: он обновляется регулярно, имеет активную сообщество и интегрируется с популярными CI/CD‑пайплайнами.

### 中文

Reel‑Kit 是一套自动化的竖版短视频生产工作台，集成了 UI 工作台、CLI 工具、20 套手绘风格模板和本地 TTS 引擎。快速使用时，只需克隆仓库，利用 CLI 将长视频切割成 9:16 片段，按需调整模板，即可直接生成可发布的 Shorts/Reels。该项目已具备生产就绪，更新频繁、社区活跃，且易于集成到 CI/CD 流程中。
