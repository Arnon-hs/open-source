**Project Summary:**

onWatch is an open-source project that tracks AI API quotas across multiple platforms, including Synthetic, Z.ai, Anthropic, Codex, GitHub Copilot, and Antigravity, in real-time. This lightweight background daemon utilizes SQLite storage and a Material Design 3 dashboard, ensuring zero telemetry. By making internal knowledge searchable and usable by assistants, onWatch aims to improve search over documents and ground assistant answers.

The primary value proposition of onWatch lies in its ability to make internal knowledge searchable and usable by assistants. This is particularly useful for organizations seeking to index knowledge bases, improve search functionality, and ground assistant answers. By utilizing onWatch, businesses can leverage their existing knowledge bases and improve the accuracy and reliability of their AI-powered assistants.
