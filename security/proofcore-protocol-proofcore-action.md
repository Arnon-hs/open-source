## 📝 Summary

### English

ProofCore offers zero‑storage release notarization for GitHub using OIDC, enabling quick verification of build integrity and authenticity. Adopt it by adding a CI script that requests an OIDC token and triggers notarization; once metadata is validated, enable automatic notarization. It’s suitable for prototypes and internal workflows, though manual dependency and maintenance checks are recommended before production use.
