## 📝 Summary

### English

Podvoice is a local‑first CLI that converts Markdown scripts into multi‑speaker podcast‑style audio using Coqui XTTS v2, enabling creators to research, generate, and publish content quickly. To adopt, install the package, write a Markdown script with speaker metadata, and run the generation command; it’s ready for prototypes and internal workflows, though dependencies should be vetted before production use.
