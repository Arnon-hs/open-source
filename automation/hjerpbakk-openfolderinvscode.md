该项目的接入方式是：

1. 在 macOS 上安装 Visual Studio Code 和 Finder 服务。
2. 在 Finder 中右键单击文件夹，选择“Open in VS Code”菜单项。
3. Visual Studio Code 将打开指定的文件夹作为项目。
