## 📝 Summary

### English

Vynody is a cross‑platform music player built with Flutter and Rust that offers a ready‑made UI and performant Rust backend for seamless audio playback in mobile apps. To adopt it, add the package to your pubspec.yaml, import the plugin, and configure playlists and controls. The project is at a prototype stage—updates are frequent, but you should verify dependency compatibility and test coverage before deploying it to production.
